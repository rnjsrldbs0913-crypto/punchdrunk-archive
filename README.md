# Punch-drunk Archive

Punch-drunk Archive는 가게에서 보유한 LP와 CD를 손님에게 보여주기 위한 정적 아카이브 사이트입니다.

손님은 QR 코드로 `index.html` 기반의 공개 화면을 보고, 관리자는 데스크탑 Chrome 또는 Edge에서 `admin.html`을 열어 음반 정보를 고칩니다.

손님용 사이트는 서버, npm, React, Next.js, Vite, 데이터베이스 없이 정적 파일만으로 작동합니다. 관리자 페이지의 Codex 번역과 자동 ZIP 생성에는 MYBOX의 `Punch-drunk Local Admin` 실행 도구를 사용합니다.

## 파일 구조

완성 폴더는 아래 구조로 되어 있습니다.

```text
punchdrunk-archive
├─ index.html
├─ admin.html
├─ styles.css
├─ app.js
├─ admin.js
├─ albums-data.js
├─ covers-list.js
├─ covers
└─ README.md
```

`index.html`은 손님용 공개 화면입니다.

`admin.html`은 관리자용 편집 화면입니다.

`albums-data.js`는 음반 데이터입니다.

`covers-list.js`는 관리자 화면에서 선택할 수 있는 커버 이미지 목록입니다.

`covers` 폴더에는 실제 커버 이미지 파일을 넣습니다.

MYBOX에서는 아래 네 항목을 같은 `개인` 폴더 안에 함께 보관합니다.

```text
Punch-drunk Archive
Punch-drunk Archive.zip
Punch-drunk Archive Backups
Punch-drunk Local Admin
```

`Punch-drunk Archive`는 관리자 파일까지 들어 있는 원본이고, `Punch-drunk Archive.zip`은 Netlify에 올리는 손님용 배포본입니다.

## 꼭 압축을 풀고 열어주세요

ZIP 파일 안에서 `index.html`을 바로 열면 안 됩니다.

압축파일 안에서 바로 열면 주소창에 `Temp`나 `.zip` 경로가 보일 수 있고, CSS나 JavaScript가 제대로 연결되지 않아 화면에 `PUNCH-DRUNK archive` 글자만 보일 수 있습니다.

해결 방법은 간단합니다.

1. ZIP 파일을 우클릭합니다.
2. 압축 풀기를 선택합니다.
3. 풀린 폴더 안의 `index.html`을 더블클릭합니다.

지인에게 ZIP으로 보낼 때도 “압축을 꼭 풀고, 풀린 폴더 안의 `index.html`을 열어달라”고 안내해주세요.

## 손님용 화면 열기

압축을 푼 뒤 폴더 안의 `index.html`을 더블클릭하면 됩니다.

손님용 화면에서는 다음을 할 수 있습니다.

- 금주의 음반 보기
- 음반 검색
- 전체 / LP / CD 필터
- 장르 필터
- 정렬 바꾸기
- 음반 목록 페이지 넘기기
- 랜덤 음반 보기
- 필터 초기화
- 커버를 눌러 상세 화면 보기
- 상세 화면에서 이전 음반 / 랜덤 음반 / 다음 음반 이동
- 상세 화면에서 트랙리스트와 설명 보기

검색 대상은 앨범명, 아티스트명, 연도, 포맷, 장르, 트랙리스트, 추천곡입니다.

앨범 설명인 `description`은 검색 대상에 포함하지 않았습니다. 개인적인 설명 문장까지 검색에 걸리지 않게 하기 위해서입니다.

음반 목록은 한 화면에 너무 길게 이어지지 않도록 3줄 분량씩 나눠서 보여줍니다. 모바일은 9장, 넓은 화면은 보통 15장 또는 18장씩 보이고, 아래의 페이지 버튼으로 넘겨볼 수 있습니다.

모바일에서는 음반 목록 영역을 좌우로 밀어 이전/다음 페이지로 넘길 수 있습니다.

랜덤 음반은 현재 검색어나 필터와 관계없이 전체 음반 중에서 고릅니다. 같은 음반이 바로 연속으로 나오지 않도록 처리되어 있습니다.

## 한글 / 영문 화면

손님용 화면 상단의 한국 국기와 미국 국기 버튼으로 한글/영문 화면을 전환할 수 있습니다.

- 검색, 정렬, 필터, 버튼, 안내 문구 같은 UI는 언어에 맞춰 바뀝니다.
- 앨범명과 트랙 제목은 번역하지 않고 원문 그대로 보여줍니다.
- 아티스트명은 관리자 화면의 `아티스트 한글표기`와 `아티스트 영문표기`가 둘 다 채워진 경우에만 언어에 맞춰 바뀝니다.
- 둘 중 하나라도 비어 있으면 기존 `아티스트` 칸의 표기를 그대로 보여줍니다.
- 설명은 한글 화면에서는 `한글 설명`, 영문 화면에서는 `영문 설명`을 보여줍니다.

관리자 화면에서 `Apple/iTunes로 표기 추정`을 누르면 알려진 표기표와 Apple/iTunes KR/US 후보를 바탕으로 아티스트 한글/영문 표기를 채웁니다. 틀릴 수 있으니 저장 전 직접 확인하세요.

`Codex로 영문 설명 채우기`는 이 컴퓨터의 Codex 앱에 로그인된 ChatGPT 계정을 사용하므로 별도의 OpenAI API 키가 필요하지 않습니다. 모델 혼잡이나 일시적인 오류가 나면 같은 요청을 한 번 자동으로 다시 시도합니다. OpenAI API 키 방식은 Codex를 사용할 수 없을 때만 쓰는 유료 예비 기능입니다.

## 관리자 화면 열기

MYBOX 동기화가 끝난 것을 확인한 뒤 `Punch-drunk Local Admin` 폴더의 `start-punchdrunk-admin.cmd`를 더블클릭하세요. 데스크탑 Chrome 또는 Edge에 관리자 페이지가 자동으로 열리고 MYBOX 원본에도 자동 연결됩니다. 폴더를 직접 선택할 필요가 없습니다.

관리자 화면에서는 다음을 할 수 있습니다.

- 새 음반 추가
- 기존 음반 수정
- 음반 삭제
- 앨범명, 아티스트, 연도, 포맷, 장르 입력
- 아티스트 한글/영문 표기 입력
- 커버 선택
- 기존 커버 목록 접기/열기와 파일명 검색
- 트랙리스트 입력
- 추천곡 체크
- 한글/영문 설명 입력
- 금주의 음반 선정 이유와 영문 선정 이유 입력
- 금주의 음반 설정
- `저장하기` 버튼 하나로 변경사항 저장
- 저장 전 필수 입력 확인
- 자동 임시 저장
- 백업 ZIP 만들기
- 손님 화면에서 현재 음반 미리보기
- Apple/iTunes에서 기본 정보, 커버, 트랙리스트 초안 가져오기
- Codex 앱의 ChatGPT 로그인으로 영문 설명 자동 생성
- 저장 전 다른 컴퓨터의 편집 여부와 MYBOX 데이터 변경 확인
- 저장 전 자동 데이터 백업
- 저장 후 Netlify용 손님 ZIP 자동 생성
- 왼쪽 음반 목록 검색, 정렬, 빠른 필터, 묶음 보기

Safari나 Firefox에서는 직접 저장 기능이 제한될 수 있습니다. 그 경우 내보내기 방식을 사용하면 됩니다.

수정 후 파일로 저장하지 않은 변경사항이 있으면 페이지를 닫을 때 확인 안내가 뜹니다.

### 다른 컴퓨터에서 이어서 작업하기

1. 먼저 사용하던 컴퓨터에서 저장 완료와 ZIP 갱신 완료 문구를 확인합니다.
2. 관리자 페이지를 닫습니다.
3. MYBOX 동기화가 끝날 때까지 기다립니다.
4. 새 컴퓨터에서 MYBOX 동기화가 끝난 것을 확인합니다.
5. 새 컴퓨터의 `start-punchdrunk-admin.cmd`를 실행합니다.

관리자 상단에 다른 컴퓨터가 편집 중이라는 경고가 보이면 저장하지 마세요. 저장 직전에 MYBOX 데이터가 달라졌다는 경고가 뜨면 현재 입력은 브라우저 임시저장본에 보존되므로, 페이지를 새로 열어 최신 자료를 먼저 확인하세요.

## 새로고침 후 입력한 자료가 안 보일 때

관리자 화면에서 많이 입력했는데 새로고침 후 사라져 보이면, 먼저 같은 브라우저에서 아래를 확인하세요.

1. 화면 상단에 `브라우저 임시 저장본 발견` 안내가 뜨면 `임시 저장본 복구`를 누릅니다.
2. 안내가 안 보이면 왼쪽의 `임시 저장 불러오기`를 누릅니다.
3. 복구가 되면 바로 `저장하기`를 누릅니다.

복구 파일이나 백업 ZIP은 안전장치입니다. 평소에는 상단의 `저장하기`를 사용하세요.

## 장르 정리 방식

장르는 직접 쓰는 칸이 아니라 정해진 목록 중에서 고르는 방식입니다.

현재 장르 목록:

```text
재즈 / 소울/펑크 / 힙합 / 알앤비 / 록 / 팝 / 일렉트로닉 / 사운드트랙 / 월드/라틴 / 한국음악 / 기타
```

Apple/iTunes에서 가져온 장르가 너무 세분화되어 있어도 큰 장르로 자동 분류됩니다.

예:

```text
Contemporary Jazz, Latin Jazz -> 재즈
Soul, Funk, Motown -> 소울/펑크
Hip-Hop/Rap, Alternative Rap -> 힙합
R&B, Contemporary R&B -> 알앤비
Alternative, Indie Rock -> 록
Soundtrack, OST -> 사운드트랙
Brazilian, Latin -> 월드/라틴
K-Pop, Korean Pop -> 한국음악
```

원하는 분류가 마음에 들지 않으면 관리자 화면의 장르 선택에서 직접 바꾸고 저장하면 됩니다.

## 커버 이미지 관리

커버 이미지는 실제로 `covers` 폴더에 저장되고, 각 음반은 `albums-data.js` 안에 `covers/파일명.jpg` 같은 경로만 기억합니다.

관리자 화면에서는 현재 선택된 커버 미리보기만 기본으로 보여줍니다. 예전에 넣어둔 커버를 다시 골라야 할 때만 `기존 커버 목록 열기`를 누르세요. 목록을 열면 파일명 검색으로 커버를 찾을 수 있습니다.

## 금주의 음반 선정 이유

`금주의 음반 선정 이유` 입력칸은 현재 음반이 금주의 음반으로 체크되어 있을 때만 보입니다.

체크를 해제해도 이미 써둔 선정 이유와 영문 선정 이유는 지워지지 않습니다. 같은 음반을 다시 금주의 음반으로 체크하면 이전에 써둔 내용이 다시 나타납니다.

## Apple/iTunes에서 초안 가져오기

관리자 화면의 `Apple/iTunes에서 초안 가져오기` 영역에서 아티스트명과 앨범명을 검색할 수 있습니다.

검색 결과는 최대 50개까지 찾고, 화면에는 10개씩 나누어 표시됩니다. 아래의 페이지 버튼으로 다음 후보를 넘겨볼 수 있습니다. Apple/iTunes의 앨범 검색에서 빠지는 한국 음반이 있어, 곡 검색에서 발견한 앨범 후보도 함께 보완해서 보여줍니다.

검색 결과는 바로 저장되지 않고, 현재 입력칸에만 적용됩니다. 적용 후에는 반드시 직접 확인하고 저장해야 합니다.

후보마다 아래 버튼을 따로 사용할 수 있습니다.

- `기본 정보+커버 적용`: 앨범명, 아티스트, 발매연도, 장르, 커버 이미지 URL을 채웁니다.
- `트랙리스트 적용`: 현재 트랙리스트를 Apple/iTunes 트랙리스트로 바꿉니다.
- `둘 다 적용`: 기본 정보, 커버, 트랙리스트를 모두 채웁니다.

음원 서비스의 트랙리스트는 실물 LP/CD와 순서나 수록곡이 다를 수 있습니다. 트랙리스트는 적용 후 실물 음반 기준으로 꼭 확인해주세요. 한국 음반은 Apple/iTunes 검색 국가를 KR로 두고 검색하세요. 트랙리스트는 선택한 국가 자료만 사용하므로, KR에서 찾지 못하면 영어권 자료로 자동 대체하지 않습니다.

일부 한국 음반은 Apple/iTunes의 앨범 조회에서는 트랙리스트가 비어 있을 수 있습니다. 이 경우 관리자 화면이 같은 국가의 곡 검색을 한 번 더 실행하되, 같은 앨범 ID 또는 정확히 같은 앨범명/아티스트로 확인되는 곡만 적용합니다. 곡 수가 현재 트랙리스트보다 너무 적거나 자료가 불안정하면 자동 교체하지 않습니다. 그래도 나오지 않는 음반은 Apple/iTunes에 자료가 부족한 경우라 직접 입력해야 합니다.

## Spotify와 Melon에 대하여

Spotify는 공식 Web API가 있어서 앨범 트랙리스트를 가져오는 기능을 만들 수는 있습니다. 다만 Spotify 개발자 앱 등록, 로그인, 토큰 발급 과정이 필요합니다. 이 프로젝트처럼 `admin.html`을 파일로 바로 여는 정적 사이트에서는 설정과 유지가 복잡해질 수 있습니다.

Melon은 브라우저에서 안정적으로 쓸 수 있는 공식 공개 API 방식이 분명하지 않습니다. 화면을 몰래 긁어오는 방식은 어느 날 갑자기 막히거나, 브라우저 보안 때문에 작동하지 않을 수 있습니다.

현재 가장 안전한 방식은 Apple/iTunes를 초안용으로 쓰고, 안 맞는 트랙리스트는 Melon이나 Spotify에서 확인한 뒤 관리자 화면의 트랙리스트 칸에 직접 붙여넣고 정리하는 것입니다.

## 브라우저 뒤로가기

손님용 페이지에서 음반 상세를 열면 주소 뒤에 `#album=음반ID`가 붙습니다. 브라우저 뒤로가기를 누르면 사이트 밖으로 나가지 않고, 직전에 보던 음반 목록으로 돌아가도록 처리했습니다.
## 저장하기

Chrome 또는 Edge에서 로컬 관리자 실행기로 관리자 페이지를 엽니다.

1. 음반 정보를 수정합니다.
2. 상단의 `저장하기` 버튼을 누릅니다.
3. 화면에 `MYBOX 작업 폴더에 자동 연결되었습니다`가 보이는지 확인합니다.
4. 화면에 `저장 완료`와 `Netlify용 ZIP 갱신 완료` 메시지가 뜨는지 확인합니다.

`저장하기`는 기존 데이터를 자동 백업한 다음 `albums-data.js`와 `covers-list.js`를 저장하고, MYBOX의 `Punch-drunk Archive.zip`을 새로 만듭니다.

컴퓨터의 보안 프로그램이 폴더 선택을 파일 첨부로 오해해 `첨부파일은 최대 150개` 같은 경고를 보여줄 수 있습니다. 로컬 관리자 실행기로 연 화면에서는 폴더 선택을 사용하지 않으므로 이 경고와 관계없이 저장할 수 있습니다. `작업 폴더 연결`과 `자동 백업 폴더 연결`은 로컬 실행기를 사용할 수 없을 때만 쓰는 예비 기능입니다.

저장하기 직전에 다른 컴퓨터의 편집 상태와 MYBOX 데이터 변경 여부를 확인합니다. 충돌 경고가 뜨면 덮어쓰지 않고 저장을 중단합니다.

평소 로컬 관리자 실행기로 연 화면에서는 폴더를 고르지 않습니다. 예비 방식의 `작업 폴더 연결`을 직접 사용한 경우에만 `covers` 폴더가 아니라 프로젝트 폴더 전체를 선택합니다.

## 저장 실패 메시지가 뜰 때

저장이 실패하면 화면 위쪽에 실패 이유가 표시됩니다.

예비 방식으로 열었을 때 흔한 경우는 아래 두 가지입니다.

- `covers` 폴더를 선택한 경우: 한 단계 위의 `punchdrunk-archive` 폴더를 다시 선택하세요.
- Chrome/Edge가 아닌 브라우저에서 연 경우: 데스크탑 Chrome 또는 Edge에서 열어주세요.

## 백업 ZIP 만들기

관리자 화면의 `현재 데이터 백업 ZIP 받기` 버튼을 누르면 현재 데이터가 들어 있는 백업 파일을 받을 수 있습니다.

작업 폴더가 연결되어 있으면 가능한 경우 `covers` 폴더의 이미지도 함께 담습니다. 연결되어 있지 않으면 `albums-data.js`, `covers-list.js` 중심으로 백업됩니다.

큰 수정 전에는 백업 ZIP을 하나 받아두면 마음이 편합니다.

## 새 음반 추가하기

1. 관리자 화면 왼쪽의 `새 음반`을 누릅니다.
2. 앨범명, 아티스트, 연도, 포맷, 장르를 입력합니다.
3. 트랙리스트와 설명을 입력합니다.
4. 커버를 추가하거나 기존 커버를 선택합니다.
5. 필요하면 `이 음반을 금주의 음반으로 설정`을 체크합니다.
6. 상단의 `저장하기`를 누릅니다.

## 기존 음반 수정하기

1. 왼쪽 목록에서 수정할 음반을 선택합니다.
2. 오른쪽 입력칸에서 내용을 고칩니다.
3. 상단의 `저장하기`를 누릅니다.

ID는 음반을 처음 만들 때 자동으로 생성되고 이후에는 고정됩니다. 앨범명이나 아티스트명을 바꿔도 ID는 바뀌지 않습니다.

왼쪽 목록이 길어지면 `음반 찾기`에 앨범명, 아티스트, 장르, 연도를 입력해서 찾을 수 있습니다.

`LP`, `CD`, `금주의 음반`, `커버 없음`, `트랙 없음`, `설명 없음` 필터를 누르면 해당 음반만 모아볼 수 있습니다.

정렬을 `아티스트순`, `앨범명순`, `장르순`, `발매순`으로 바꾸면 목록 중간에 묶음 제목이 표시됩니다.

현재 편집 중인 음반을 다시 찾고 싶으면 왼쪽의 `현재` 버튼을 누르면 됩니다.

## 음반 삭제하기

1. 왼쪽 목록에서 삭제할 음반을 선택합니다.
2. 오른쪽 위의 `현재 음반 삭제`를 누릅니다.
3. 확인창에서 삭제를 승인합니다.
4. 저장합니다.

삭제한 뒤에는 되돌리기 어렵습니다. 삭제 전에는 내보내기로 백업 파일을 받아두면 안전합니다.

## 금주의 음반 바꾸기

금주의 음반으로 보여줄 음반을 선택한 뒤 `이 음반을 금주의 음반으로 설정`을 체크합니다.

새 음반을 금주의 음반으로 체크하면 다른 음반들의 금주의 음반 설정은 자동으로 꺼집니다. 금주의 음반은 하나만 유지됩니다.

`금주의 음반 선정 이유` 칸에 문장을 적으면 손님용 첫 화면의 금주의 음반 카드 오른쪽 아래에 표시됩니다.

관리자 화면 상단의 `현재 음반을 금주의 음반으로` 버튼을 누르면 지금 편집 중인 음반을 바로 금주의 음반으로 바꿀 수 있습니다.

## 트랙리스트 입력하기

트랙리스트는 한 줄에 한 곡씩 입력합니다.

예:

```text
A1. The Genesis
A2. N.Y. State of Mind
A3. The World Is Yours
```

곡 번호가 없어도 작동하지만, LP나 CD 트랙 번호를 넣으면 화면에서 더 보기 좋습니다.

## 추천곡 체크하기

트랙리스트를 입력하면 아래에 추천곡 체크박스가 생깁니다.

추천하고 싶은 곡을 체크하면 손님용 상세 화면의 트랙리스트에서 그 곡 왼쪽에 작은 점이 찍힙니다.

추천곡은 별도 섹션으로 따로 보이지 않습니다.

표시 순서는 아래처럼 곡 번호의 왼쪽입니다.

```text
● A1. N.Y. State of Mind
  A2. Life's a Bitch
● A3. The World Is Yours
```

## 커버 이미지 추가하기

가장 쉬운 방법은 관리자 화면에서 `탐색기에서 커버 추가`를 사용하는 것입니다.

1. 음반을 선택합니다.
2. `탐색기에서 커버 추가`를 누릅니다.
3. 이미지 파일을 선택합니다.
4. 선택한 이미지는 미리보기로 표시되고, `저장하기`를 누를 때 `covers` 폴더에 복사됩니다.
5. `covers-list.js` 목록에도 자동으로 추가됩니다.
6. 현재 편집 중인 음반의 커버로 자동 적용됩니다.
7. 마지막에 `저장하기`를 누릅니다.

로컬 관리자 실행기로 연 화면에서는 폴더를 따로 선택하지 않습니다. 이미지를 고른 뒤 `저장하기`만 누르면 원본 커버와 목록용 썸네일이 MYBOX에 함께 저장됩니다. 작업 폴더 선택은 로컬 관리자 실행기를 사용할 수 없을 때만 쓰는 예비 방식입니다.

이미지 선택 후 저장하기 전에 관리자 페이지를 새로고침하면 브라우저가 원본 이미지 파일을 다시 잡을 수 없습니다. 그 경우 이미지를 다시 선택한 뒤 `저장하기`를 눌러주세요.

파일명이 중복되면 자동으로 `-1`, `-2` 같은 번호가 붙습니다.

예:

```text
illmatic.jpg
illmatic-1.jpg
illmatic-2.jpg
```

## 커버 이미지 파일명 규칙

권장하는 파일명:

- 영어 소문자
- 숫자
- 하이픈
- `.jpg`, `.png`, `.webp`

좋은 예:

```text
moon-beams.jpg
illmatic.jpg
songs-in-the-key-of-life.webp
```

피하는 것이 좋은 예:

```text
문빔스 최종.jpg
Moon Beams!.jpg
cover image.jpg
```

커버 이미지는 반드시 `covers` 폴더 안에 있어야 합니다.

## Netlify에 업로드하기

손님들이 QR로 접속하려면 인터넷 주소가 필요합니다. Netlify에 올리면 정적 사이트 주소를 만들 수 있습니다.

기본 순서:

1. 관리자 화면에서 저장하고 `Netlify용 ZIP 갱신 완료`를 확인합니다.
2. Netlify에 로그인합니다.
3. 배포 화면에 MYBOX의 `Punch-drunk Archive.zip`을 드래그 앤 드롭합니다.
4. 업로드가 끝나면 휴대폰으로 사이트를 새로 열어 최신 음반이 보이는지 확인합니다.

자동 생성되는 ZIP에는 손님용 파일만 들어갑니다. `admin.html`, `admin.js`, `recovery.html`, `README.md`는 MYBOX 원본에는 그대로 남아 있지만 공개 ZIP에서는 제외됩니다.

나중에 정식 도메인을 연결해도 같은 ZIP을 계속 사용하면 됩니다. 온라인에서 직접 수정하는 관리자 시스템을 별도로 만들게 되면 그때 인증과 온라인 저장 기능을 갖춘 관리자 페이지를 다시 배포할 수 있습니다.

## QR 코드로 연결하기

Netlify에서 만든 사이트 주소를 QR 코드 생성 사이트에 넣으면 됩니다.

예:

```text
https://your-site-name.netlify.app
```

QR 코드가 만들어지면 휴대폰으로 스캔해서 공개 화면이 잘 열리는지 확인하세요.

## 화면에 PUNCH-DRUNK archive만 보일 때

원인은 대부분 ZIP 파일 안에서 `index.html`을 바로 열었기 때문입니다.

이 경우 CSS와 JavaScript가 제대로 연결되지 않아 로고만 보일 수 있습니다.

해결 방법:

1. ZIP 파일을 압축 풉니다.
2. 풀린 폴더 안의 `index.html`을 엽니다.
3. 주소창에 `Temp`나 `.zip`이 보이지 않는지 확인합니다.

## 데이터 파일을 직접 볼 때

`albums-data.js`에는 음반 정보가 들어 있습니다.

각 음반은 아래 항목을 가집니다.

```text
id
title
artist
year
format
genre
coverImage
artistKo
artistEn
recommendedTracks
tracklist
description
descriptionEn
weeklyReason
weeklyReasonEn
isWeekly
```

`format` 값은 `Vinyl` 또는 `CD`를 사용합니다. 손님용 한국어 화면에서는 `Vinyl`을 `LP`로, 영문 화면에서는 `Vinyl`로 보여줍니다.

코드를 잘 모른다면 이 파일을 직접 고치기보다 `admin.html`에서 수정하는 것을 추천합니다.
## 추천 운영 방식

원본은 MYBOX의 `Punch-drunk Archive` 하나만 관리합니다.

1. MYBOX 동기화가 끝난 뒤 로컬 관리자 실행기를 엽니다.
2. 수정 후 `저장하기`를 누릅니다.
3. 자동 백업과 `Punch-drunk Archive.zip` 갱신 완료를 확인합니다.
4. MYBOX 동기화가 끝난 뒤 ZIP만 Netlify에 올립니다.

관리자용 원본을 따로 복사하지 않기 때문에 어느 폴더가 최신인지 헷갈리지 않습니다. 다른 컴퓨터에서는 반드시 MYBOX 동기화가 끝난 뒤 작업하세요.

## 새 관리 도구

관리자 페이지에는 아래 점검 도구가 들어 있습니다.

- `관리 현황`: 전체 음반 수, 커버 없음, 트랙 없음, 영문 설명 없음 등을 숫자로 보여줍니다. 숫자 카드를 누르면 해당 음반만 왼쪽 목록에 표시됩니다.
- `임시저장 관리`: 브라우저에 남은 임시저장본을 확인하고, 복구하거나 ZIP으로 받을 수 있습니다. 오래된 임시저장본이 헷갈리면 모두 비울 수 있습니다.
- `커버 정리 점검`: 안 쓰는 커버, 경로 확인이 필요한 커버, 여러 음반이 함께 쓰는 커버를 보여줍니다. 작업 폴더가 연결되어 있으면 실제 `covers` 폴더까지 읽어 목록 밖 파일과 사라진 파일도 구분합니다. 점검 결과는 TXT 보고서로 받을 수 있으며 파일은 자동으로 삭제하지 않습니다.
- `커버 자동 최적화`: 새로 고른 큰 이미지는 긴 변 2000px 안쪽의 웹용 JPG로 복사됩니다. 원본 파일은 내 컴퓨터에 그대로 남고, 이미 저장된 기존 커버는 자동으로 바꾸지 않습니다.
- `목록용 썸네일`: 원본 커버는 금주의 음반과 상세 화면에 그대로 쓰고, 음반 목록에는 `covers/thumbs`의 480px 이미지를 사용합니다. 새 커버를 저장하면 썸네일도 함께 만들어집니다.

이번 개선 전 전체 상태와 기능별 복구 안내는 MYBOX의 `Punch-drunk Archive Backups` 폴더에 보관합니다.
